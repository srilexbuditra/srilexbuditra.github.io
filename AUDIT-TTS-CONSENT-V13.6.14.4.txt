AUDIT TTS + CONSENT — PROJECT 2026-09-15

Temuan utama penyebab posisi consent mobile belum konsisten:
1. visitor-analytics.js masih memanggil:
   /assets/css/privacy-consent.css?v=13.6.14.2
   sehingga browser dapat tetap memakai CSS cache lama walaupun file produksi
   sudah ditimpa dengan V13.6.14.3.
2. Panel consent dibuat sebagai elemen <section>.
   style.css halaman utama memiliki aturan mobile global untuk `section`,
   sehingga panel consent ikut masuk ke sistem layout halaman utama.
3. V13.6.14.4 mengisolasi panel menjadi <div role="region"> dan memakai
   viewport lock khusus mobile.
