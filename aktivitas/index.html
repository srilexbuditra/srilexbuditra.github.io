HOW TO READ THIS PAGE

Status dibuat eksplisit.

COMPLETED berarti milestone telah selesai pada scope yang dicatat. COMPLETED / LOCKED berarti baseline telah selesai dan tidak dibuka kembali tanpa regression nyata atau approved scope change. LIVE SYSTEM berarti layanan publik aktif. FRONTEND STABLE / DESIGN LOCKED berarti frontend dan identitas visual sudah stabil sementara fase berikutnya dapat tetap berjalan. PRODUCTION VERIFIED berarti release telah diterbitkan dan diperiksa pada runtime production. ACTIVE ARCHITECTURE berarti arsitektur tersebut menjadi baseline aktif untuk area publik terkait.
