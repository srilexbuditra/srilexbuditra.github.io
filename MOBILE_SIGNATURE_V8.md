# V8 Mobile Signature & PDF Fix

- Pihak Pertama menggunakan tanda tangan digital terdaftar.
- Pihak Kedua tetap menggambar tanda tangan sendiri.
- Data tanda tangan Pihak Kedua disimpan sebagai data URL setelah pointer selesai agar selalu tersedia saat PDF dibuat.
- Modal agreement mobile menggunakan 100dvh, width 100vw, overflow-x hidden, scrolling vertikal, safe-area padding, dan layout satu kolom.
- Canvas signature mengikuti lebar container tanpa overflow horizontal.
- Tombol dan kartu pihak dibuat full-width pada mobile.
