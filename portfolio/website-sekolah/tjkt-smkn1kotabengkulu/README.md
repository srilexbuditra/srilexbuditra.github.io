# Website Kelas X TJKT — SMK Negeri 1 Kota Bengkulu

Website statis responsif untuk informasi Kelas X TJKT (Teknik Jaringan Komputer dan Telekomunikasi).

## Isi
- `index.html` — halaman utama
- `assets/style.css` — desain responsif
- `docs/data-foto-siswa.pdf` — PDF sumber yang dapat dibuka, diunduh, dan dicetak

## Publikasi
Upload seluruh isi folder ke hosting statis seperti GitHub Pages, Cloudflare Pages, atau hosting sekolah. Jangan menghapus struktur `docs/` karena tombol PDF mengarah ke file tersebut.

## Catatan privasi
PDF sumber berisi data siswa. Pastikan sekolah dan pihak yang berwenang menyetujui publikasi dokumen tersebut sebelum website dibuat publik.
