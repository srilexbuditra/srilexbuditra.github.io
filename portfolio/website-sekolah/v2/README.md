# Portofolio Sekolah V2
Website HTML/CSS/JavaScript untuk GitHub Pages. Kartu portofolio membuka `detail.html?id=...` dengan deskripsi, tanggal, kategori, lokasi, peserta, tujuan, hasil, galeri dan portofolio terkait. Data ada di `data.js`. Ganti placeholder galeri dengan foto asli sekolah pada tahap produksi.
