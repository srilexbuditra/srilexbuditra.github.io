# Portofolio Website Sekolah
Website statis HTML/CSS/JavaScript yang responsif untuk GitHub Pages.

## File
- index.html
- style.css
- script.js
- assets/school-preview.avif

## Cara mengganti data
Edit nama sekolah, statistik, judul kartu, deskripsi, tanggal, email, dan gambar pada `index.html`.

## GitHub Pages
Upload seluruh isi folder ke repository GitHub Pages, lalu aktifkan Pages dari branch utama.
