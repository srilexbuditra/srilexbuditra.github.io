02 / CHALLENGE → APPROACH

Menyatukan informasi, persiapan, dan pendampingan dalam satu pengalaman.

Challenge

Banyak kebutuhan dalam satu perjalanan.

Jemaah membutuhkan informasi, manasik, checklist, agenda, dokumen, dan bantuan tanpa kehilangan konteks tahap persiapan.

Approach

Memisahkan pengalaman berdasarkan peran.

Dashboard Admin berfokus pada pekerjaan operasional, sementara Journey Dashboard berfokus pada progres dan langkah berikutnya untuk jemaah.

Outcome

Fondasi platform yang dapat tumbuh.

Autentikasi serta manajemen Admin dan Jemaah sudah terhubung ke D1, sedangkan data operasional lanjutan dipindahkan bertahap ke backend resmi.
