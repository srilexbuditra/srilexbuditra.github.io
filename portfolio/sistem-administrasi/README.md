# Adminfolio V1 — Portofolio Sistem Administrasi

Website portofolio responsif berbasis HTML, CSS, dan JavaScript.

## Fitur
- Dashboard admin/portofolio
- Statistik proyek
- Kartu portofolio interaktif
- Modal detail proyek
- Galeri screenshot + lightbox
- Pencarian dan filter kategori
- Sidebar responsif/mobile
- Dark mode dengan localStorage
- Data contoh yang mudah diganti
- Tanpa backend/database

## Struktur
- `index.html`
- `style.css`
- `script.js`

## Menjalankan
Buka `index.html` di browser. Untuk GitHub Pages, upload ketiga file ke repository dan aktifkan Pages.

## Mengganti data
Edit array `projects` di `script.js`. Ganti gambar contoh `picsum.photos` dengan screenshot proyek Anda sendiri.

## Catatan
Data, statistik, nama proyek, dan gambar pada versi ini adalah data contoh.
