# POS Portfolio V1

Portofolio aplikasi Point of Sale dengan:
- Dashboard statistik
- Project cards clickable
- Detail project modal
- Galeri screenshot + lightbox
- Dark mode
- Responsive sidebar
- Responsive mobile/tablet/desktop
- Animasi hover
- Timeline pengembangan
- Technology stack
- CTA kontak
- Data demo yang mudah diganti

## Cara menggunakan
1. Buka `index.html` di browser.
2. Ganti nama brand, logo, deskripsi, data statistik, teknologi, dan link kontak.
3. Untuk GitHub Pages, upload `index.html` ke repository lalu aktifkan Pages.

## Catatan
Semua screenshot dashboard pada versi ini berupa mockup HTML/CSS sehingga tidak memerlukan aset gambar eksternal.
