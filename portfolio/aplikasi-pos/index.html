Project Overview

Informasi lengkap proyek portfolio.

POSPro — Point of Sale System

Aplikasi POS dirancang untuk membantu bisnis retail, restoran, dan berbagai jenis usaha dalam mengelola operasional penjualan secara efisien dan terintegrasi.

Desain menggunakan pendekatan dashboard modern agar pengguna dapat memahami informasi penting dengan cepat.
