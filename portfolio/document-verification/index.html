01 / SYSTEM SNAPSHOT

Trust layer yang fokus pada pemeriksaan, bukan sekadar QR.

QR adalah pintu masuk. Keaslian tetap ditentukan oleh record verifikasi dan status dokumen.

StatusActive Foundation

QR BoundaryNo personal data

SecurityPublisher V31

Publisher Token tidak disimpan permanen pada localStorage.

02 / CHALLENGE - APPROACH

Dokumen resmi membutuhkan mekanisme verifikasi yang dapat diperiksa ulang.

Challenge

QR saja tidak cukup.

Kode visual perlu terhubung ke sumber pemeriksaan yang dapat menentukan apakah Document ID benar-benar memiliki record valid.

Approach

Pisahkan public verification dan publishing.

Public verification membaca record, sementara publisher action membutuhkan jalur authenticated dan secret server-side.

Outcome

Verification dengan fallback.

Verification page dapat memeriksa API dan memakai static registry sebagai fallback tanpa mengubah QR target.
