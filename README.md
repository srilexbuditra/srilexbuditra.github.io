# Srilex Buditra — Maintenance Page

## Struktur
- `index.html` — seluruh HTML, CSS, dan JavaScript dalam satu file.
- `assets/maintenance-hero.png` — artwork maintenance yang dibuat untuk halaman ini.

## Cara menjalankan
Buka `index.html` langsung di browser, atau upload seluruh folder ke hosting.

## Yang perlu disesuaikan sebelum production
1. Ubah `targetDate` di bagian JavaScript jika jadwal maintenance sudah pasti.
2. Ganti URL social media placeholder pada bagian footer.
3. Jika ingin form email benar-benar mengirim notifikasi, hubungkan `#notifyForm` ke backend/email service.
4. Jika gambar OG akan dipakai di production, upload `assets/maintenance-hero.png` ke path yang sama di domain.
