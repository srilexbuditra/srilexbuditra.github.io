05 / PEMELIHARAAN

Maintenance Mode ON / OFF

Pelajari pengalaman kontrol pemeliharaan sebelum fitur nyata dibuat. Tombol ini sama sekali tidak mengubah layanan, server, atau pengguna lain.

KONTROL PRATINJAU

Status Maintenance

OFF · NORMAL

Di staging DEV, status Maintenance dibaca dari API; di pratinjau lokal tetap simulasi. Kontrol perubahan terkunci.

Konfirmasi dan pencatatan audit di bawah ini juga hanya simulasi browser.
