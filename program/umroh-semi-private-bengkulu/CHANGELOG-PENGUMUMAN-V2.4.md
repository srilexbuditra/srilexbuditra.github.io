# Pengumuman Jemaah V2.4

## Added
- Halaman `/jamaah/pengumuman/`.
- Empat pengumuman simulasi dengan kategori Manasik, Dokumen, Perjalanan, dan Keamanan.
- Status `Tandai dibaca` yang disimpan lokal melalui `localStorage` (`umroh-announcements-read-v1`).
- Filter kategori pengumuman.
- Sinkronisasi daftar Pengumuman Terbaru dan jumlah notifikasi belum dibaca ke Dashboard Jemaah.

## Changed
- Menu `Pengumuman` dan tombol `Lihat semua` pada Dashboard Jemaah membuka halaman Pengumuman nyata.
- Catatan prototype Dashboard menjelaskan bahwa Pengumuman V2.4 sudah aktif secara lokal.

## Safety
- Seluruh isi V2.4 masih data simulasi dan tidak boleh dianggap sebagai informasi operasional resmi sebelum dipublikasikan pengelola.
