# Agenda & Perjalanan Jemaah V2.2 — 2026-09-17

## Added
- Halaman `/jamaah/agenda/` untuk Agenda & Perjalanan Jemaah.
- Timeline 4 agenda simulasi untuk menguji pengalaman pengguna.
- Informasi rencana keberangkatan, waktu, dan titik kumpul.
- Tombol `Tandai dibaca` dengan penyimpanan lokal browser (`umroh-agenda-read-v1`).
- Ringkasan agenda terdekat pada Dashboard Jemaah.
- Sinkronisasi tampilan tanggal keberangkatan dan countdown Dashboard dengan sumber data Agenda simulasi.
- Panduan ringkas perjalanan dari materi Manasik: ketepatan titik kumpul, ketertiban jadwal, dan kontak penting.

## Changed
- Menu sidebar, kartu cepat Agenda, dan navigasi mobile Dashboard Jemaah sekarang membuka halaman Agenda nyata.
- Catatan prototype Dashboard diperbarui untuk membedakan modul aktif dengan data operasional simulasi.

## Important
- Semua tanggal, waktu, lokasi, dan status agenda pada V2.2 adalah **data simulasi**.
- Jadwal ini bukan jadwal perjalanan resmi dan harus diganti dengan data yang dipublikasikan pengelola saat backend/admin Agenda dibuat.
- V2.2 belum terhubung ke autentikasi, API, database, atau Dashboard Admin.
