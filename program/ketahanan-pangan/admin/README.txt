TEMPLATE SERTIFIKAT A4 FINAL

File utama:
- certificate-template-a4-final.png : background A4 kosong untuk sistem.
- preview-posisi-data.png           : contoh posisi nama peserta.

Data yang harus ditampilkan sebagai overlay dinamis:
1. Nama peserta: area tengah setelah slogan dan sebelum blok informasi.
2. ID Sertifikat.
3. Nomor Registrasi.
4. Wilayah.
5. Status Terverifikasi.
6. QR Code verifikasi.
7. Tanggal penerbitan/otomatis.

Prinsip:
Background tidak berisi data peserta sehingga tidak terjadi teks/QR ganda.
Logo, ornamen pertanian, judul, blok verifikasi dan footer tetap menjadi bagian visual background.
