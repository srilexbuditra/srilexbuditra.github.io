V3.7 — FIX MESIN EXCEL

Masalah ditemukan:
index.html hanya memuat SheetJS dari cdn.sheetjs.com. Jika domain itu gagal/terblokir, window.XLSX tidak pernah tersedia dan muncul pesan “Mesin Excel belum termuat”.

Perbaikan:
- Tambah excel-engine-loader.js.
- Loader mencoba 4 sumber secara berurutan: cdnjs, jsDelivr, unpkg, lalu SheetJS CDN.
- Tombol ekspor menunggu mesin Excel benar-benar siap sebelum membuat XLSX.
- script utama diganti nama menjadi script-a4-v37.js untuk memutus cache lama.

UPLOAD / REPLACE di program/ketahanan-pangan/admin/:
1. index.html
2. excel-engine-loader.js
3. script-a4-v37.js

Deploy -> Ctrl+F5 -> login admin -> Ekspor Excel A4.
